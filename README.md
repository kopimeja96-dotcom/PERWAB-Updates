# PERWAB — unduhan aplikasi

**Belum ada installer stabil yang diterbitkan. OTA belum aktif.**

Repository ini disiapkan sebagai lokasi distribusi installer TIPIDTER, SIBER, dan edisi lain yang telah lolos pengujian dan tinjauan. Bukan tempat data operasional atau kode pengembangan privat.

## Persyaratan yang direncanakan
- Windows 10/11 x64 yang masih memperoleh pembaruan keamanan.
- Microsoft Edge atau Google Chrome.
- Python dan pustaka dibundel oleh installer: tidak perlu memasang Python/pip sendiri.
- Word dan Excel disediakan serta dilisensikan sendiri oleh pengguna bila diperlukan untuk edit/cetak.
- Google Drive Desktop opsional untuk arsip sinkron. Internet diperlukan untuk unduhan update dan fitur daring yang dipakai.

## Status
Kode dan proses build kandidat internal berada dalam repository privat. Build Windows, uji instalasi/upgrade, keputusan aset unit, serta pengaman OTA harus selesai sebelum paket dipublikasikan. Feed kosong bukan updater yang sudah berfungsi.

Font generator milik pengguna dapat disertakan berdasarkan klarifikasi pemilik. Database, master anggota, Coklit, data perkara, kredensial dan template yang belum ditinjau tidak boleh diunggah di sini.

## Download dan update
Setelah tersedia, installer resmi akan muncul pada tab **Releases** beserta versi, edisi, checksum, dan catatan perubahan. Saat ini tidak ada tautan installer aktif. Jangan memakai paket TIPIDTER untuk SIBER atau sebaliknya.

Repository Tipidter-Data-Control yang sudah ada tidak diubah oleh penyiapan distribusi ini.
